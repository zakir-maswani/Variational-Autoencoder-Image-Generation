## 📌 Overview

A standard autoencoder compresses an image into one fixed latent vector. A **Variational Autoencoder (VAE)** instead encodes each image into a *probability distribution*, which makes the latent space smooth and continuous and allows the model to **generate new data**.

| | Autoencoder | Variational Autoencoder |
|---|---|---|
| Encoder output | One fixed latent vector `z` | A distribution (mean `μ` and variance) over `z` |
| Latent space | Irregular, with gaps | Smooth and continuous, close to a standard normal |
| Can generate new data? | Not reliably | Yes: sample `z ~ N(0, I)` and decode it |

This project trains a convolutional VAE on Fashion-MNIST and demonstrates reconstruction, **image generation**, **latent-space interpolation** and **latent-space visualisation**.

Evaluated on the 10,000 Fashion-MNIST test images (loss is the negative ELBO per image).

### Learning curves

Train and validation loss decrease together and stay close, indicating no significant overfitting. The reconstruction term falls quickly while the KL term stabilises at around 17.7.

## 🏗️ Model Architecture

```
Image (1×28×28)
        │
  ┌─────▼──────┐   Conv2d(1→32, stride 2)   28×28 → 14×14
  │  ENCODER   │   Conv2d(32→64, stride 2)  14×14 → 7×7
  └─────┬──────┘   Flatten (3136)
        │
   ┌────┴─────┐
   ▼          ▼
  μ (16)   logvar (16)         ← two linear heads
   └────┬─────┘
        │   Reparameterisation: z = μ + σ · ε,  ε ~ N(0, I)
        ▼
  Latent vector z (16)
        │
  ┌─────▼──────┐   Linear(16→3136) → reshape 64×7×7
  │  DECODER   │   ConvTranspose2d(64→32, stride 2)  7×7 → 14×14
  └─────┬──────┘   ConvTranspose2d(32→1, stride 2)   14×14 → 28×28 + Sigmoid
        │
Reconstruction (1×28×28)
```

| Property | Value |
|---|---|
| Trainable parameters | 191,265 |
| Latent dimension | 16 |
| Activations | ReLU (hidden), Sigmoid (output) |

### Loss function (negative ELBO)

$$\mathcal{L} = \underbrace{\text{BCE}(\hat{x}, x)}_{\text{reconstruction}} + \beta \cdot \underbrace{D_{KL}\big(q(z|x)\,\|\,\mathcal{N}(0,I)\big)}_{\text{latent regularisation}}$$

- **Reconstruction:** Binary Cross-Entropy summed over all pixels
- **KL divergence:** keeps the latent distribution close to a standard normal, which is what makes sampling and interpolation work
- **β** controls the trade-off: larger values give a smoother latent space but blurrier images

## ⚙️ Training Setup

| Setting | Value |
|---|---|
| Optimizer | Adam, learning rate 1e-3 |
| β (KL weight) | 1.0 (standard VAE) |
| Batch size | 128 |
| Epochs | 15 |
| Data split | 55,000 train / 5,000 validation / 10,000 test |
| Seed | 42 |

Labels are **not** used for training. They are used only to colour the latent-space plot and to pick image pairs for interpolation.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the notebook

```bash
jupyter notebook vae_fashion_mnist.ipynb
```

Fashion-MNIST is downloaded automatically on the first run. A GPU is used if available, but the model is small enough to train on CPU.

### Load the trained model

After running the notebook, the weights are saved to `vae_fashion_mnist.pth`. To reuse them:

```python
model = VAE(latent_dim=16)
model.load_state_dict(torch.load("vae_fashion_mnist.pth"))
model.eval()

# Generate new images
z = torch.randn(64, 16)
images = model.decode(z)
```

## 🔬 Ideas for Further Experiments

- Vary `BETA` (e.g. 0.5 or 4.0) to study the sharpness vs. latent smoothness trade-off (β-VAE)
- Vary `LATENT_DIM` (2, 8, 32). With 2 you can plot the latent space directly and decode a grid of it
- Build a **Conditional VAE** by feeding the class label to the encoder and decoder to generate a specific item on demand
- Move to a colour dataset such as CelebA with a deeper convolutional network
